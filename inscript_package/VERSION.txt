Bug Fixes (v3.9.2):
  ✅ Fix 1: import "string" module — all 30 functions restored
     stdlib_bugfixes.py was calling register_module("string", ...) which
     replaced the full string module with only {replace, Regex}.
     Changed to _MODULES["string"].update(...) so it merges correctly.
     Affected: replace_all, trim_start, trim_end, split_lines, find_last,
               remove, truncate, index_of, slice, split, join, upper,
               starts_with, ends_with, and 15 other string functions.

  ✅ Fix 2: generator for-in / gen.next() returning empty/nil
     visit_GeneratorFnDecl builds gen_interp via object.__new__() but
     did not initialise _ic_fn_lookup, _ic_struct_fields, or _deferred.
     First name lookup in the generator body hit _ic_fn_lookup.get()
     → AttributeError, silently swallowed by except Exception: pass,
     killing the generator thread instantly before any yield.
     Added the three missing attribute initialisations.
